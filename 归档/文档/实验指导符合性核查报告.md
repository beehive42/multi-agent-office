## 四、缺陷分级清单

### P0 —— 直接影响功能验收（必须修）

1. **PDF 导出缺失且被主动禁止**
   `system.py` 第 334 行 `只输出 Markdown 正文，不导出 PDF`、第 398 行 `不要导出 PDF`；`run_full()` 只写 `.md`。
   → 指导书测试场景 1 的核心要求落空。OpenClaw 自带 `nano-pdf` skill 与 `clawpdf` 依赖，技术上并不难补。

2. **模块 5 全部交付物为 0**
   部署文档、体系结构图、架构分析报告（≥2000 字）、最终实验报告、答辩 PPT 全无。这一块占 20 分，且是"架构答辩"的主要抓手。

3. **WebUI 统一入口跑不完一个完整任务**
   实测：主 Agent 用 `sessions_spawn` 依次拉起 manager/planner/data 子会话后，`sessions_yield` 返回，本轮即以空回复结束，`office-collab/outputs/` 没有产出。

4. **WebUI 链路会让 DataAgent 编造数据**
   主 Agent 自行给 DataAgent 的提示词是：「若缺少真实数据，请基于合理假设给出示例性结构化数据，但必须明确标注为示例」——与指导书"数据整理：调用本地文件、简单数据接口"和"不得编造"直接冲突，也绕开了已经写好的 `data_service.py`。

### P1 —— 影响交付物与答辩质量

5. **`sessions_wait` 工具不存在**
   `openclaw-workspace/AGENTS.md` 指示主 Agent 使用 `sessions_spawn` 与 `sessions_wait`。本版本（2026.10.9）实际只有 `sessions_spawn / sessions_send / sessions_list / sessions_history / sessions_search / sessions_yield`，**没有 `sessions_wait`**；等待语义应使用 `sessions_yield` 或 `wait`。

6. **AGENTS.md 里的运行命令路径错误**
   文档写 `.\\.venv\\Scripts\\python.exe .\\office-collab\\system.py ...`，但 Agent 的工作目录是 `openclaw-workspace`，实测直接报"无法将 .\\.venv\\Scripts\\python.exe 识别为 cmdlet"。应改为绝对路径或先 `Set-Location` 到项目根。

7. **`verify-route` 是硬编码返回值**
   不执行任何调用却返回 `ok: true`，无法作为链路证据。

8. **Checker 缺数字一致性硬校验**
   目前"数据是否正确"完全交给 LLM。建议在 `markdown_checks.py` 加一条：把 data 里的数值集合与正文做差集，缺一即 error（本次人工比对是 17/17 通过，但不可持续依赖模型）。

9. **`system.py health` 在网络关未启动时直接抛 30s 超时堆栈**
   未做 `AgentFailure` 包装，输出不友好，且违背"异常处理"要求。

10. **planner / data 的 `IDENTITY.md` 仍是 Researcher 模板**
    两者 `Name: Researcher`、`Vibe: curious, evidence-led research`，与"规划专员""数据专员"角色不符；`openclaw.json` 里 planner/data 的 `theme` 同样是 researcher 文案。

### P2 —— 工程整洁度

11. `openclaw-workspace/BOOTSTRAP.md` 未按约定在初始化后删除。
12. `data_service.py` 第 13 行 `import yaml` 未使用。
13. `run_full()` 输出文件名是 `{run_id}.md`，现在两个交付文件是人工改名的；缺 `--output-name` 之类参数。
14. 无 README / 使用说明；无任何自动化测试（`pytest` 已装但未用）。
15. `安装记录.md` 第 6 节"大模型 API 待配置"已过期，与现状矛盾。

5. **容错**：Agent 调用失败重试 2 次后改派 `main`，并落 `retry` / `reassign` 事件。
