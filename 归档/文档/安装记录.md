## 2. 与指导书安装步骤的差异（重要）

指导书 3.1.2 节按“Python + pip + `python openclaw/gateway.py`”描述 OpenClaw，这与 2026 年官方版本不一致。实际安装以官方文档为准：

- OpenClaw 官方仓库：<https://github.com/openclaw/openclaw>
- 官方文档：<https://docs.openclaw.ai>
- 官方要求 Node.js 24.16+（推荐 24.22.1+）或 Node 26；核心程序不是 Python 包。
- 启动命令是 `openclaw gateway run`，不是 `python openclaw/gateway.py`。
- 指导书中的 `https://github.com/openclaw-team/openclaw` 不是本项目仓库，未使用。

Python 3.12 环境仍已单独准备好，用于后续按指导书开发 Agent 脚本、处理 Markdown/CSV/DOCX 和调用大模型 API。

## 4. 使用方法

在 PowerShell 中进入本目录：

```powershell
. .\activate.ps1
openclaw --version
```

启动 Gateway（前台运行，Ctrl+C 停止）：

```powershell
.\start-openclaw.ps1
```

或直接：

```powershell
.\openclaw.cmd gateway run --port 8000 --bind loopback
```

打开控制台：

```text
http://127.0.0.1:8000/
```

带登录 Token 的地址可用：

```powershell
.\open-webui.ps1
```

Token 保存在 `.openclaw\gateway-token.txt`，不要提交到代码仓库或发给他人。
