## 二、旧版脚本\

这些是 OpenClaw 早期的手工启动脚本，功能已被 `deploy\` 下的脚本完全覆盖（且新脚本多了幂等、就绪探测、日志落盘等能力），留在根目录容易和新入口混淆，故移入此处。

| 文件 | 原来做什么 | 现在用什么 |
| --- | --- | --- |
| `activate.ps1` | 把 `tools\` 下的 Node/Python 加入当前会话 PATH | 不需要：`deploy\*.ps1` 与 `system.py` 都用绝对路径 |
| `openclaw.cmd` | 不激活 PATH 也能调 OpenClaw 的包装入口 | `tools\npm-global\node_modules\.bin\openclaw.cmd` |
| `start-openclaw.ps1` | 前台启动网关 | `deploy\start-gateway.ps1` |
| `stop-openclaw.ps1` | 调 `openclaw gateway stop` 停止网关 | `deploy\stop-gateway.ps1`（按端口定位，清理更彻底） |
| `open-webui.ps1` | 带 Token 打开控制台 | `deploy\launch.ps1`（自动打开控制台） |

## 四、如何恢复或删除

- **恢复某个文件**：把文件从本目录移回根目录即可，例如
  `Move-Item .\归档\旧版脚本\start-openclaw.ps1 .\`
- **整体删除**：确认不再需要后，直接删除整个 `归档` 目录即可，不影响系统运行：
  `Remove-Item .\归档 -Recurse -Force`
